# 전체 플레이테스트 반영

2026-09-09. 사용자가 제공한 사건 1~8 전체 플레이 보고서에 따라 진행을 막는 안내 문제와 반복 조작을 수정했다. 기존 사건 정답, 자동 근거 연결, 저장 키와 저장 구조는 유지한다.

## P1

| 보고된 문제 | 수정한 동작 |
| --- | --- |
| 이전 검색 조건에 다음 사건 글이 가려짐 | 검색어·분류·사진 필터를 칩으로 표시한다. 새 글 중 가려진 개수를 알리고 한 번에 필터 해제·최신순·첫 페이지·새 글 반영을 수행한다. 기존 검색 유지도 제공한다. |
| 20:14:00 오답 처리 | HH:MM과 HH:MM:SS를 정규화한다. 20:14와 20:14:00은 같으며 20:14:01은 다르다. 잘못된 형식은 입력란에서 알리고 저장하지 않는다. |
| V03이 맞아도 선행 원문 미열람 때문에 일반 오류 발생 | 선행 원문 제목과 바로 열기 버튼을 표시한다. 확인 전 조회는 비활성화하며 값은 유지한다. 엔진 오류도 선행 원문 부족과 조회 대상 불일치를 구분한다. |

정확한 번호를 먼저 맞혔는지는 원문 확인 전에 공개하지 않는다. 문항별 정오답을 숨기는 추리 검증 정책도 유지한다.

## 조작과 읽기

- 추리 노트에서 필수 직접 조사 1개를 명시하고 완료 전에는 검증을 잠근다. 답안 입력은 허용한다. 2화에서는 점검·영상 원문을 먼저 읽고 대조 화면을 열 수 있다.
- 5~8화 조사판은 읽은 원문 항목을 펼쳐 놓고 연결할 위치를 한 번 선택한다. 관찰·배치를 동시에 저장하고, 다른 위치에 중복 연결하지 않는다. 출처와 선택 결과를 계속 비교할 수 있다. 추론을 대신 작성하지 않는다.
- 파쇄 조각은 사용자가 정한 10개를 유지한다. 전체를 화면 폭에 맞춰 보고 확대해 읽으며, 선택한 조각의 교환 위치를 목록에서 고를 수 있다. 키보드·터치·드래그와 기존 저장을 유지한다. 자동 정렬이나 정답 조각 고정은 제공하지 않는다.
- 프롤로그는 첫 문단, 이번 조사의 이유, 두 가지 행동을 먼저 보여 준다. 앞선 이야기의 나머지는 펼쳐 읽는다. 목표는 기존 모달 안에 있다.
- 엔딩 진입 시 원문·노트·조사·힌트 등의 중간 창을 정리한다. 버튼·Escape·바깥 클릭으로 나가면 사건 목록으로 복귀하며, 다른 엔딩을 다시 읽을 수 있다. 조사 창에도 닫았을 때 돌아갈 위치를 안내한다.
- 원문 본문은 16px, 반복해서 읽는 조사·입력 설명은 14px로 보완했다. 완료·미선택 조사 항목에 일괄 투명도를 적용하지 않아 내용을 읽을 수 있다. 모바일 폭에서는 조사 입력을 한 열로 배치한다.
- 첨부 수량을 단일 문장으로 표시하고 변경을 알린다. 미리 듣기에는 요청 횟수·현재 설정 음량을 표시한다. 실제 스피커에서 들렸다고 판단하는 표시는 아니다.

## 서사

6-2 감사 이력에 M01의 작업 메모를 추가했다. 전출 안내를 이용해 서윤의 결산 이의를 현 거주자 민원에서 제외하고 후속 글을 중복으로 정리하려 했다는 연결이다. 새로운 인물이나 사건, 정답은 추가하지 않았다.

7화의 윤해진은 당시의 상황을 회상하는 구어체로, 서윤은 걱정시킨 이웃에게 직접 안부를 전하는 짧은 문장으로, 오유진의 첨부 설명은 원본을 남긴 이유를 담은 고백으로 다듬었다. 현재 확인의 시각, 과거 목격과의 차이, 지시와 실행의 구분은 ‘기록자 메모’로 별도 보관한다. 조회·검색에서도 이 메모를 찾을 수 있다.

## 검증 범위

최종 로컬 전체 검사 114개 통과. 타입·린트, Pages·Worker 빌드, 로컬 Pages 파일·번들·저장 복원 검사와 HTTP 전체 캠페인도 통과했다.

새 회귀 검사는 필터가 유지된 사건 전환과 새 글 복구, 형식 오류와 초 단위 입력, 원본 조회 중 선행 원문 열기·돌아오기·값 보존, 필수 CCTV 대조 안내, 후반부 직접 선택의 저장 실패·재시도·재접속을 다룬다. 기존 8화 UI 캠페인에 새 선택 방식과 두 엔딩·모달 정리·초기화 확인을 포함했다. 파쇄 문서는 전체 보기·확대·자리 선택·키보드·드래그·복원·저장 복원을 확인한다.

화면 동작은 JSDOM 검사이며 실제 Chrome 렌더링, 모바일 터치와 스피커 음질·음량 균형을 새로 검증한 것은 아니다. HTTP 전체 8화·두 엔딩·저장 복원·세션 격리 검사, 타입·린트, Pages와 Worker 빌드도 수행한다. GitHub Actions의 전체 검사 후 공개 주소의 번들과 브라우저 저장 복원을 확인한다.
