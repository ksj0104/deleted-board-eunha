## 실행한 검증

- `npm test`: 7개 테스트 통과. UI 테스트 한 개가 8화 전체 48개 기록과 24개 가설을 화면 컨트롤로 실제 수행한다. React + jsdom을 사용하며 브라우저 화면 촬영 테스트는 아니다.
- `npm run typecheck`: 통과.
- `npm run test:http`: 개발 서버에서 전체 캠페인과 세션 저장 확인.
- `npm run build`: vinext 5단계 배포 빌드 통과. `/`는 요청 헤더로 메타데이터를 생성하므로 빌더의 정적 경로 분류가 `?`로 표시되지만 실제 HTML 요청은 200이다.
- `wrangler dev --config dist/server/wrangler.json --port 3001 --local --persist-to .wrangler/production-test`로 빌드된 Worker를 실행한 뒤 `GAME_TEST_URL=http://127.0.0.1:3001 npm run test:http`: 전체 캠페인, 두 결말, 세션 격리, 초기화, HTML·자산 확인 통과.
- 악성 형식 요청 점검 중 한 차례 로컬 서버에서 일시적으로 503이 관측되었다. 같은 서버의 해당 요청을 직접 재검증했을 때 400이었고 전체 캠페인 재실행도 통과했다. 당시 게임의 정상 요청과 저장 검증은 모두 통과했다.

## 확인 한계

이 환경의 in-app Browser에는 사용 가능한 브라우저가 없었다. 실제 브라우저 스크린샷·화면 배치·네이티브 모달 초점/터치 동작을 검증했다고 주장하지 않는다. UI 제어는 jsdom, 배포 런타임과 데이터 저장은 실제 로컬 Worker/D1 HTTP 요청으로 확인했다. 로그인으로 보호되는 게시 주소의 인증 이후 화면은 사용자 브라우저에서 확인할 수 있다.
