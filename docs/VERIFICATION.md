## 실행

- `npm test`: 9개 테스트 통과. React + jsdom으로 게시판/중첩 모달 동작과 8화 전체 풀이를 검증한다.
- `npm run typecheck`, `npm run lint`: 통과. 이미지는 사전 압축된 정적 WebP이므로 Next 이미지 서비스 권고는 앱 파일에서 제외했다.
- `npm run test:http`: 개발 서버에서 8화 전체와 실제 저장소 검증 통과. 개발 서버와 배포 산출물의 서로 다른 CSS/JS 경로를 모두 검사한다.
- `npm run build`: vinext 5단계 빌드 통과. 요청 헤더를 사용하는 메타데이터 때문에 경로 분류는 `?`지만 HTML 응답은 200이다.
- 빌드된 Worker를 로컬 포트 3001에서 실행하고 `GAME_TEST_URL=http://127.0.0.1:3001`에서 HTTP 캠페인을 검증했다. D1은 `.wrangler/production-test` 아래의 로컬 테스트 저장소를 사용했다.
- 최초 로컬 산출물 검사에서 이미지 요청 하나가 지연되었다. 로컬 서버 출력을 읽은 뒤 완료되었으며, 이후 직접 요청과 나머지 13개 이미지·CSS·JS는 모두 정상 응답했다. 최종 산출물 서버 로그는 파일에 보관한다.

## 확인 한계

최종 HTTP 검증에서 다른 출처의 요청을 거부한 직후 같은 연결의 다음 요청이 로컬 Worker에서 503으로 중단되는 현상을 재현했다. 요청 본문을 소비한 뒤 출처 오류를 반환하도록 수정했다. 연속 오류 요청의 403 → 400 응답을 세 차례 확인하고 최종 배포 산출물에서 8화 전체·두 결말·저장·이미지·정적 자산 검증을 모두 통과했다.

이 환경의 in-app Browser에는 사용 가능한 브라우저가 없었다. 실제 브라우저 스크린샷·화면 배치·네이티브 모달 초점 및 터치 동작을 검증했다고 주장하지 않는다. UI 제어와 상태 보존은 jsdom에서, 배포 런타임과 데이터 저장은 실제 로컬 Worker/D1 HTTP 요청으로 확인했다. 로그인으로 보호되는 게시 주소의 인증 이후 화면은 사용자 브라우저에서 확인할 수 있다.
