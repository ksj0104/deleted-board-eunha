# 주민 게시판 100개 글 확장 — 2026-09-08

키워드를 발견하고 다른 글로 이어 읽을 수 있도록 주민 글 100개를 추가했다. 기존 112개 기록에 더해 전체 기록은 212개이며, 공개 글 180개와 비공개 자료 32개로 구성한다.

## 글의 구성과 시간

| 항목                           | 추가분 |
| ------------------------------ | -----: |
| 사건 전 생활 기록, 03.01~03.18 |   80개 |
| 이후 후속 글, 03.19~03.25      |   20개 |
| 작성자                         |   33명 |
| 게시판 분류                    |   26종 |
| 댓글                           |  139개 |
| 첨부 표                        |   19개 |
| 사진을 포함한 글               |    7개 |

각 글은 2문단, 본문 150~220자로 작성했다. 모임 질문과 후기, 거래·교환·대여, 생활 민원, 설문, 공동구매, 자료 공유, 분실물, 음식, 사진과 동물 이야기를 섞었다. 기존 이미지 6종 중 필요한 사진을 재사용하며 새 파일을 생성하지 않았다.

최초 세계 시각에는 기존 17개와 새 과거 글 80개를 합한 **97개 공개 글**이 열린다. 추가분의 후속 글은 03.19~03.24에 하루 3개, 03.25에 2개다. 기존 세계 시각과 접근 검사를 그대로 적용한다. 댓글은 게시 후 7·14·21분으로 기록하며, 각 글이 처음 노출되는 시점보다 미래에 있는 댓글은 없다.

원래 48개 핵심 기록과 64개 일상 글의 ID와 본문은 유지한다. 새 과거 글은 `1-15`~`1-94`, 후속 글은 각 날짜에 배정한 별도 ID를 사용한다. 진행 저장 형식과 답안 판정은 변경하지 않는다.

## 검색으로 이어 읽는 예

- **시집 → 모임 취소**: 반납 질문 `1-51`을 읽고 원래 모임 공지 `1-4`를 찾는다. 반납 후기 `2-15`는 다음 세계 시각부터 나타난다.
- **초록 우산**: 분실 `1-58` → 발견 제보 `1-64` → 주인이 찾았다는 후기 `1-67`을 날짜순으로 대조한다.
- **영수증 → 영수증 주전자**: 초기 결과 10개를 2개로 좁혀 보관 질문과 파일 나눔 글을 연결한다.
- **동문 → 동문 공사**: 초기 결과 6개를 원래 공사 공지 1개로 좁힌다.
- **책등 종이테이프**: 글 제목에 없는 말도 `1-66` 첨부 표에서 찾아 일치한 행을 보여 준다.

질문 주머니, 의자 패드, 펌프 대여, 옷걸이 반환, 장바구니 공동구매, 사진 전송, 씨앗 나눔, 수리 후기에도 후속 글이 있다. 주민 글은 기존 사건을 알아볼 맥락을 더하지만 계정 동일성이나 비공개 기록의 사실을 대신 입증하지 않는다.

검색은 공백으로 나눈 모든 단어를 포함하는 글을 찾는다. 제목·작성자·분류·본문·댓글·첨부 제목과 표·기록 ID를 대상으로 하며 단어가 서로 다른 필드에 있어도 일치한다. 대소문자와 NFKC 문자 차이를 정규화하고, 강조할 때에는 원문 문자를 유지한다. 본문·댓글·첨부의 출처를 표시한 일치 문맥을 최대 2개 제공한다. 결과의 기존 정렬 순서는 바꾸지 않는다.

분류는 검색 아래 선택 상자로 정리했다. 검색·분류를 바꾸면 첫 페이지로 이동하고, 글·증거·추리 모달을 닫으면 이전 검색 상태를 유지한다. 새 글은 기존처럼 **새 글 N개 반영**을 눌러 목록에 추가한다.

## 내용 검토와 검증

글 100개의 제목·ID·문단 중복, 본문 길이, 첨부 열 수, 사진 파일, 초기/후속 접근, 댓글 작성 시각을 검사했다. 꽃이 피는 시점은 기존 03.20 글에 맞춰 이른 사진 글을 지난봄 회상으로 구성했다. 개인이 집에서 진행하는 책 나눔은 작은도서관 공사 중 접수와 혼동되지 않도록 장소를 밝혔다. 과거 글을 나중에 수정했다고 주장하는 표현도 새 후기로 정리했다.

- `npm test`: **70/70 통과**. 기존 8화·24개 추리·두 결말·저장, 즉시 반응하는 증거 선택, 게시판 연속성, 새 검색과 원문 열람을 포함한다.
- `npm run typecheck`, `npm run lint`: 통과. UI 테스트의 선택 상자 타입 단언 수정 후 해당 검색 흐름을 별도로 재검증했다.
- `npm run build`: vinext 배포 산출물 생성 통과. 빌드한 Worker를 로컬 포트 3001에서 실행하고 `npm run test:http`로 8화·두 결말·D1 저장·세션 격리·오류 응답을 확인했다. 새 과거 글 수집·저장 유지, 후속 글의 날짜별 열람, 이미지 14개와 HTML 메타데이터·CSS·JS 제공까지 통과했다.
- 검색 단위 검사는 필드별 AND 검색, 댓글·표 문맥, 전각 문자·조합 한글·합자, 겹치는 단어, 이모지 경계와 HTML 문자의 원문 보존을 포함한다.

UI 상호작용은 React + jsdom에서 검증했다. 실제 브라우저 화면 배치·터치 조작을 확인했다고 주장하지 않는다.
