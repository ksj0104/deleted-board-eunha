# 직접 조사와 자동 추리 노트

설명문에서 결론을 읽고 근거를 체크하던 흐름을 원문 조사 → 관찰 항목 배치·비교 → 결과 확인 → 가설 작성으로 바꿨습니다. 2화의 CCTV 기록 대조와 3화 파쇄 쪽지 복원은 유지하고, 나머지 에피소드에 사건별 조사대를 추가했습니다.

## 원문과 조작

해당 기록은 원본 뷰어로 표시합니다. 계정 정보·금액란·서명·봉인 등을 펼칠 수 있고, 첨부표는 문서 형태로 남습니다. 동봉 설명과 텍스트 원문은 접어 두되 검색과 접근성을 위해 보존합니다. 사진이 아닌 디지털 기록·서식·시설 연결도를 HTML/CSS로 표현했으며 기존 사진 자산은 재사용합니다.

조사대는 기록 창이나 추리 노트의 ‘직접 조사 열기’에서 열립니다. 원문을 열람한 뒤 해당 자료를 사용할 수 있습니다. 항목을 눌러 조사하고 배치 칸을 누르는 방식은 키보드와 터치에서도 동작합니다. 데스크톱에서는 펼친 항목을 끌어 놓을 수 있습니다. 원문 창을 위에 열어도 조사대와 게시판의 상태는 유지됩니다.

조사 결과 확인은 필요한 원문과 모든 대응 관계를 검증합니다. 임의의 배치·중복 항목·열람하지 않은 출처·미해금 사건은 인정하지 않습니다. 4화는 배치만으로 통과하지 않으며 전원을 끈 모형에서 내부 손잡이를 조작해야 합니다. 오답에 정답 배치를 공개하지 않습니다. 결과 확인에 성공하면 대조한 원문을 증거 보관함에 자동 수집합니다.

## 추리 노트

‘가설을 뒷받침하는 증거’ 및 수동 근거 선택 영역을 제거했습니다. 단순히 글을 읽거나 일정 개수 이상 모으는 것으로 문항이 나타나지 않습니다. 수집한 증거 안에서 해당 문항의 모든 사실을 입증하는 조합이 성립해야 나타납니다. 대체 원문 조합을 인정하고 관련 없는 글은 계산에서 제외합니다.

질문은 답안만 작성합니다. 검증 시 최신 수집 상태에서 근거 조합을 자동으로 선택하며, 사건별 직접 조사 확인도 필요합니다. 증거 수집 해제 때문에 미해결 질문이 숨겨져도 기존 답안과 메모는 유지합니다. 다시 수집하면 답안과 함께 나타납니다. 이미 해결한 사건은 이전 저장을 포함해 문항과 해설을 유지합니다.

검증 실패는 전체 추리에 대한 공통 안내만 표시합니다. 문항별 정오답, 부분 입증 표시, 부족한 근거의 자동 힌트, 맞힌 개수를 공개하지 않습니다. 준비 상태·준비 개수·해결 목표의 다음 조사 추천은 입력과 수집 상태만으로 정하므로 검증 결과로 오답 위치가 드러나지 않습니다. 사건 전체 해결 뒤에는 입증 완료와 해설을 표시합니다. 직접 조사의 배치 확인과 사용자가 여는 관찰 힌트는 기존 방식으로 유지합니다.

## 저장과 검증

진행 버전 1 및 기존 브라우저 저장 키를 유지합니다. 선택 필드 `investigations`에 조사별 관찰 항목·배치·확인 여부를 저장합니다. 즉시 조작하고 뒤에서 순차 저장하며 실패한 배치는 창을 닫았다 열어도 유지하여 재시도할 수 있습니다. 새로고침으로 복원하는 것은 저장에 성공한 상태입니다. 이미 완료한 조사 재플레이는 기존 완료를 취소하지 않습니다.

`tests/fieldwork.test.ts`는 독립 공략의 배치, 접근 조건, 누락·오배치, 정전 개방 시험, 자동 근거 대체 조합, 저장 실패·손상·이전 저장·초기화를 검증합니다. UI 캠페인은 8화 모두를 실제 컴포넌트 조작으로 완료합니다. 별도 UI 검사는 키보드·드래그, 모달 유지, 저장 실패와 재시도·재접속, 질문 자동 노출·수집 해제 후 답안 보존을 확인합니다. UI 상호작용 검증은 JSDOM을 사용합니다.
