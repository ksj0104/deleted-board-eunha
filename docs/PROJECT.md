# 삭제된 게시판 — 은하아파트 기록

현재 저장소에는 사전 게임 기획이 없었으므로, 대화에서 추천한 인터넷 탐색 추리를 기준으로 8화 완결 캠페인을 구성한다. 모든 에피소드 개발은 아래 전체 캠페인의 구현·검증을 의미한다.

## 완료 요구사항

- 공개 배포는 GitHub Pages를 사용한다. 계정 로그인이나 게임 서버 없이 실행하며 각 플레이어의 Chrome/브라우저 `localStorage`에 진행·증거·답안·메모를 자동 저장한다. 같은 주소와 브라우저에서 다시 접속하면 복원한다. 기존 Worker/D1 배포 구조는 별도 실행 경로로 유지한다.
- 중심 사건은 연락이 끊긴 서윤의 상황과 그녀의 기록이 지워지는 이유다. 플레이어는 독서모임 기록을 맡던 이웃이며 서윤과 모임을 준비하던 중 연락이 끊겼다.
- 개별 추리는 중심 사건에 접근하기 위해 필요한 확인이다. 관련 기록을 읽으면 의문과 조사 이유, 알아낸 사실의 쓰임이 나타나며, 다음 화는 앞선 발견의 미해결 지점에서 시작한다.
- 8화 모두 이미지 프롤로그, 중심 의문과 조사 이유, 논증 3개, 힌트 3단계, 해결 해설을 갖춘다. 핵심 기록 48개와 일상 글 164개의 작성 구분은 화면에서 교체되는 게시판 묶음을 뜻하지 않는다.
- 180개 공개 글은 게시 시각에 따라 누적되고, 32개 비공개 기록은 출처를 명시한 8번의 회신·인계로 도착한다. 게시판은 현재 선택한 사건과 독립적이며 이전 사건을 방문해도 글이 사라지지 않는다.
- 새로 추가한 100개 글 중 80개는 사건 전 기록이며, 최초 공개 글은 97개다. 후속 20개는 시간에 따라 추가한다. 복수 키워드 AND 검색, 일치 문맥과 강조를 지원한다.
- 새 공개 글은 알림을 누를 때 목록에 반영한다. 도착만으로 읽던 목록이 밀리지 않으며, 반영할 때도 검색·분류·정렬·페이지를 유지한다.
- 증거 보관함과 추리 노트는 게시판 검색·페이지를 유지하는 모달이다. 추리 노트에서 증거 원문을 다시 열어 대조할 수 있다.
- 증거 체크와 답안은 즉시 반영한다. 대기 중인 같은 질문의 저장은 최신 상태로 모으고, 응답 지연·실패 때 선택을 보존한다. 검증은 최신 답안의 저장 성공 뒤에만 실행한다.
- 추리 노트의 근거는 검색·출처 필터·8개씩 페이지로 찾고, 선택한 근거는 위에서 바로 해제한다. 근거 수는 질문별 최소~최대 범위이며 필요한 사실을 모두 입증하는 대체 조합도 인정한다. 관련 없는 자료나 핵심 사실이 빠진 조합은 통과시키지 않는다.
- 공감과 프롤로그 열람 여부를 저장한다. 필드가 없는 이전 버전 저장 기록도 기존 증거·메모·답안을 유지한다.
- 닉네임 추적, 시간선, 장부, 경로, 백업 연결, 게시 이력, 증언, 종합 입증의 서로 다른 추리를 구현한다.
- 읽기, 검색/게시판 필터, 증거 수집, 근거 선택, 객관식/코드/순서 입력, 오답 재도전, 순차 해금 및 재열람이 동작한다.
- D1에 익명 세션별 진행·읽음·증거·메모·답안·힌트를 자동 저장한다. 다른 세션과 격리한다.
- 마지막에는 개인정보를 가린 주민 공개 / 감사기관 한정 제출의 두 결말이 있으며 양쪽 모두 기록은 보존된다.
- 모바일·키보드·줄어든 동작 선호를 지원하고 오류·로딩·빈 검색 결과·저장 실패를 표시한다.
- 콘텐츠/엔진 테스트로 8화 전체 정답·오답·근거 검증·잠금·힌트·재개·양쪽 결말을 확인한다. 실제 HTTP API로 전체 캠페인과 새 세션 격리를 검증한다.
- 완성된 사이트를 빌드하고 Sites에 비공개 게시한다. 외부 권한/서비스 장애로 불가하면 정확한 증거와 남은 작업을 기록하며 완료로 주장하지 않는다.

## 에피소드

1. 이사 간 사람 — P042 계정 동일성과 전출 모순, 달빛세탁소 약속.
2. 7분의 빈틈 — C2 +7분, 출입 20:14 → 복사 20:17 → 동문 20:21 → 정전 20:24.
3. 두 장의 영수증 — 공사비 180만, 차액 300만, 다온기획과 조민석.
4. 열리지 않는 동문 — 관리동 → 동문 안뜰 → 지하 연결통로 → 구 세탁실(주민 기록실).
5. 찢어진 백업 — C A D B 연결, 보관함 0318, 원본 E42.
6. 관리자의 문장 — M01 실제 작성, 표결 없는 폐쇄, 회계/수정 이력만 삭제.
7. 침묵의 이유 — 서윤의 자발적 보호, 오유진의 제보, 차단 지시와 직접 조작의 구분.
8. 사라지지 않을 기록 — 독립 원본 대조, 사실/미확정 분리, 공개 범위 결정, 완결.

등장인물·장소·서류는 모두 창작이다. 시간과 동선, 명시적 사실 및 불확실성은 위 정본을 따른다.

## 조사가 이어지는 이유

1. 전출 설명을 본인의 말과 대조하려고 계정을 확인한다. 쪽지의 약속 상대는 마지막 소식을 물어볼 사람이다.
2. 약속에 오지 못한 구간을 확인한다. 잘못된 시각으로 만들어진 침입 설명을 검증한다.
3. 복사가 침입으로 설명된 이유를 찾기 위해 자료의 내용과 돈의 흐름을 확인한다.
4. 금전 사본에서 발견한 이해관계만으로 공지 조작을 단정할 수 없다. 서윤의 다음 행적과 원본이 남은 장소를 좁힌다.
5. 보관 색인을 복원해 사본을 검증할 원본 묶음을 확보한다.
6. 원본의 계정·수정 이력과 폐쇄 실행 계획을 대조해 실제 행위와 보존 대상을 특정한다.
7. 서윤 본인의 안전과 제보자의 출처를 확인한 뒤 자료를 맡길 수 있는지 판단한다. 지시와 직접 실행을 구분한다.
8. 독립 보관 원본으로 최종 주장을 확인하고, 미확정 사실과 보호 정보를 구분해 공개 범위를 결정한다.
