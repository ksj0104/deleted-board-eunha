# 삭제된 게시판 — 은하아파트 기록

현재 저장소에는 사전 게임 기획이 없었으므로, 대화에서 추천한 인터넷 탐색 추리를 기준으로 8화 완결 캠페인을 구성한다. 모든 에피소드 개발은 아래 전체 캠페인의 구현·검증을 의미한다.

## 완료 요구사항

- 8화 모두 독립적인 이미지 프롤로그, 사건 상황과 해결 목표, 핵심 기록 6개와 주민 일상 글 8개, 논증 3개, 힌트 3단계, 해결 해설을 갖춘다.
- 게시글 총 112개를 사진·댓글·조회수·주민 프로필·나눔/처리 상태와 함께 주민 커뮤니티로 구성한다. 시간의 흐름에 따라 일상 글의 후기가 이어진다.
- 증거 보관함과 추리 노트는 게시판 검색·페이지를 유지하는 모달이다. 추리 노트에서 증거 원문을 다시 열어 대조할 수 있다.
- 공감과 프롤로그 열람 여부를 저장한다. 필드가 없는 이전 버전 저장 기록도 기존 증거·메모·답안을 유지한다.
- 닉네임 추적, 시간선, 장부, 경로, 백업 연결, 게시 이력, 증언, 종합 입증의 서로 다른 추리를 구현한다.
- 읽기, 검색/게시판 필터, 증거 수집, 근거 선택, 객관식/코드/순서 입력, 오답 재도전, 순차 해금 및 재열람이 동작한다.
- D1에 익명 세션별 진행·읽음·증거·메모·답안·힌트를 자동 저장한다. 다른 세션과 격리한다.
- 마지막에는 개인정보를 가린 주민 공개 / 감사기관 한정 제출의 두 결말이 있으며 양쪽 모두 기록은 보존된다.
- 모바일·키보드·줄어든 동작 선호를 지원하고 오류·로딩·빈 검색 결과·저장 실패를 표시한다.
- 콘텐츠/엔진 테스트로 8화 전체 정답·오답·근거 검증·잠금·힌트·재개·양쪽 결말을 확인한다. 실제 HTTP API로 전체 캠페인과 새 세션 격리를 검증한다.
- 완성된 사이트를 빌드하고 Sites에 비공개 게시한다. 외부 권한/서비스 장애로 불가하면 정확한 증거와 남은 작업을 기록하며 완료로 주장하지 않는다.

## 에피소드

1. 이사 간 사람 — P042 계정 동일성과 전출 모순, 달빛세탁소 약속.
2. 7분의 빈틈 — C2 +7분, 출입 20:14 → 복사 20:17 → 동문 20:21 → 정전 20:24.
3. 두 장의 영수증 — 공사비 180만, 차액 300만, 다온기획과 조민석.
4. 열리지 않는 동문 — 관리동 → 동문 안뜰 → 지하 연결통로 → 구 세탁실(주민 기록실).
5. 찢어진 백업 — C A D B 연결, 보관함 0318, 원본 E42.
6. 관리자의 문장 — M01 실제 작성, 표결 없는 폐쇄, 회계/수정 이력만 삭제.
7. 침묵의 이유 — 서윤의 자발적 보호, 오유진의 제보, 차단 지시와 직접 조작의 구분.
8. 사라지지 않을 기록 — 독립 원본 대조, 사실/미확정 분리, 공개 범위 결정, 완결.

등장인물·장소·서류는 모두 창작이다. 시간과 동선, 명시적 사실 및 불확실성은 위 정본을 따른다.
