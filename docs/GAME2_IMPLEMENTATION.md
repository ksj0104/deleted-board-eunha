# 마지막 커튼콜 — 첫 플레이 버전

공개 경로: `https://ksj0104.github.io/deleted-board-eunha/#curtain-call`

## 구현 범위

다섯 장의 조사와 두 가지 작별 장면을 연결했다. 첫 게임은 기존 주소에 남으며, 사이드바 또는 모바일 상단의 ‘게임 2’ 링크로 이동한다. 첫 게임으로 돌아와도 각각의 진행을 유지한다.

| 장 | 플레이어의 조작 | 완료 시 남는 관찰 |
| --- | --- | --- |
| 1 | 세 목격 시점의 시야 도해와 확대 창 비교 | 얼굴을 확인한 목격은 없었다 |
| 2 | 막과 조명 전환, 의자 위치 조절 / 녹음 선택과 파형 시작점 정렬 | 마네킹의 윤곽과 재사용한 녹음 |
| 3 | 세트 위치 비교, 연결된 통로 이동 / 파편 이동·회전, 전후 착용 확인 / 연속 구간 위치 비교 | 가능한 은폐 동선, 물리적 접촉, 거짓 위치 설명 |
| 4 | 옛 도면 이동·회전, 보관 표식으로 서랍 선택, 덧붙인 표지 들어 올리기 | 정다은의 작품과 마지막 다툼의 이유 |
| 5 | 확인한 결과를 자동 배치한 재현에 인물 선택, 사건 흐름 재생 | 사건 해결과 두 가지 작별 |

긴 설명은 사건 모달과 발견 보관함에 둔다. 화면에는 현재 조작 안내와 짧은 결과를 표시한다. 파편·도면은 포인터 캡처를 사용하며, 방향키·Shift 방향키·이동/회전 버튼으로도 조작한다. 허용 오차 안에서 맞추면 정확한 위치에 붙는다. 이미 발견한 내용은 보존하되, 나중에 틀린 배치를 대조했을 때 성공으로 잘못 표시하지 않는다.

## 원본과 재현

무대·백스테이지·소품 시트는 생성한 PNG 세 장이다. 같은 소품을 재사용해 그림자, 작업등, 파편을 표시한다. 소품 시트의 배경은 실제 투명도가 아닌 RGB 체크무늬이므로, 의상 장식의 물체 경계는 화면에서 잘라 쓰고 무대 그림자는 밝기를 투명도로 옮기는 렌더링 필터로 만든다. 파일 자체는 원본을 보존한다. 독립 생성한 시간대별 이미지의 우연한 차이를 정답으로 사용하지 않는다.

시야·공간·인물 위치는 기능적 도해다. 화면에서 고정 원본과 재현을 구분한다. 인물의 움직임은 실사 동영상이 아니며, 음향 비교에는 인사 직전의 비언어적 마이크 점검 소리를 쓴다. 네 WAV와 파형은 같은 PCM에서 나온다. `npx tsx scripts/curtain-audio.ts`로 다시 생성할 수 있다.

## 저장과 배포

- 별도 저장 키: `eunha.last-curtain.progress.v1`.
- 조사 도중의 위치·회전·슬라이더·발견·장·결말을 즉시 저장한다.
- 저장 차단이나 공간 부족은 오류로 표시하고 현재 조작 상태에서 재시도한다.
- 손상된 저장은 자동 덮어쓰기하지 않는다. 초기화는 확인 창을 거치며 첫 게임의 키를 바꾸지 않는다.
- GitHub Pages에서는 게임 API를 호출하지 않는다. 같은 프로젝트 하위 경로의 이미지와 음원만 사용한다.
- 기존 Pages/Worker 엔트리를 유지하고 게임 선택만 추가했다. `.openai/hosting.json`, 원래 저장/서버 방식과 공유 이미지는 유지한다.

## 검증

기존 114개에 두 번째 게임 관련 10개를 추가했다. 엔진의 오답·선행 조건·조작 오차, 다섯 장의 실제 React 컨트롤 진행, 중간 재접속, 두 결말, 포인터 취소, 키보드 이동, 저장 오류/초기화, 첫 게임과 저장 분리를 검증한다. WAV 파일과 파형 원본의 일치도 검사한다.

정적 배포 검사에서는 두 게임의 실제 프로덕션 번들을 JSDOM에서 실행하고 하위 주소의 41개 게임 이미지, 공유 이미지, 네 WAV를 요청한다. 두 게임 시작, 저장 복원, 마지막 커튼콜 완료 저장 및 결말 전환과 API 미사용을 확인한다. Pages와 Worker 빌드, TypeScript, lint도 확인한다.

실제 Chrome의 시각 렌더링, 실기기 터치 감각, 실제 스피커 음질·음량과 플레이 시간/난이도는 이 자동 검증에 포함되지 않는다. 반응형 배치와 확대 모드는 구현했으며 해당 항목은 후속 사용자 플레이테스트로 확인한다.
