## 3화 입력 개선

- 자료 탭 이동 → 접힌 항목 펼치기 → 배치 칸 클릭을 자료 옆 선택 목록의 한 번 입력으로 줄였다.
- 금액 / 두 이체 / 업체·승인자를 세 구역으로 정리했다. 선택한 공사비와 별도 이체를 다음 구역에서도 참고할 수 있다.
- 선택한 두 금액으로 차액을 계산한다. 계산 결과는 선택값 기준이며, 잘못 연결한 이체는 검증을 통과하지 못한다.
- 미열람 등록부의 값은 공개하지 않는다. 원문을 위에 열었다 닫으면 대조 화면으로 돌아오며 자료가 표시된다.
- 기존 임의 배치, 입력 해제, 중복 배치 방지, 저장 실패 후 창 재열기·재시도, 완료 후 재접속을 확인했다.

## 이미지 검수

CCTV 5장과 3화 문서 원본 4장을 직접 열어 확인했다. 점검 영상은 열림 → 닫힘 → 열림이며, 사건 영상은 열린 관리동 문 → 닫힌 문과 동문 쪽 이동이다. 문서의 작업번호·금액·계좌 끝자리·수취인 가림·승인 정보가 텍스트 원본과 일치한다. 파쇄 조각 10장은 자동 검사에서 원본과 모든 RGB 픽셀이 일치하게 재구성됐다.
